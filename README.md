# Acessibilidade no Dia a Dia

Projeto desenvolvido para a disciplina de Desenvolvimento Web do curso de Engenharia de Software.

O objetivo é apresentar conceitos de acessibilidade na Web de forma simples e demonstrar algumas dessas práticas na própria aplicação.

## Acesse o projeto

O site está publicado e pode ser acessado em:

https://acessibilidade-web-silk.vercel.app

## Funcionalidades

- Navegação entre 6 páginas
- Ajuste do tamanho do texto
- Modo de alto contraste
- Navegação por teclado
- Foco visível nos elementos
- Link para pular diretamente ao conteúdo principal
- Estrutura semântica em HTML
- Checklist interativo de acessibilidade
- Layout responsivo

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Páginas

- Início
- Acessibilidade
- Barreiras
- Boas práticas
- Teste de acessibilidade
- Sobre

## Acessibilidade

O projeto utiliza práticas como hierarquia de títulos, links descritivos, contraste adequado, navegação por teclado, HTML semântico e recursos ARIA.
