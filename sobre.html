Sobre o projeto

Aluno: Gustavo Kucharski Baruffi
Curso: Engenharia de Software
Disciplina: Desenvolvimento Web

Este site foi desenvolvido como atividade da disciplina de Desenvolvimento Web do curso de Engenharia de Software.

O objetivo do projeto é estudar conceitos de acessibilidade e aplicar algumas boas práticas durante o desenvolvimento de uma aplicação Web.

Tecnologias utilizadas

  • HTML: estrutura e organização do conteúdo.
  • CSS: cores, tamanhos e disposição dos elementos.
  • JavaScript: controles de acessibilidade e checklist.

Práticas aplicadas neste projeto

  • HTML semântico.
  • Navegação por teclado.
  • Foco visível.
  • Títulos organizados.
  • Links descritivos.
  • Opção de aumentar o texto.
  • Modo de alto contraste.
  • Layout responsivo.
  • Linguagem simples.
